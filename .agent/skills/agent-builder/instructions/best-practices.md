# Agent Builder Best Practices

- **Naming Convention:** All skills must use `kebab-case` for the directory and file names.
- **Personality Block:** Always start the personality with "You are a **[Role]** responsible for...".
- **Instruction References:** Use human-readable link text for all instruction references in the agent file.
